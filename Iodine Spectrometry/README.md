**# Computational Physics**



**Numerical modelling of orbital motion and gravitational perturbations using low-order integration schemes.**



**The project compared Euler--Cromer and second-order Runge--Kutta methods for Keplerian orbits, tested numerical convergence and timestep sensitivity, and extended the model to non-integrable multi-body systems.**



**## Methods**

**- Python numerical simulation**

**- Euler--Cromer integration**

**- Second-order Runge--Kutta integration**

**- Timestep refinement and convergence testing**

**- Energy and angular-momentum diagnostics**

**- Multi-body gravitational modelling**



**## Key Results**

**- Confirmed numerical convergence under timestep refinement**

**- RK2 produced substantially improved accuracy over Euler--Cromer at fixed timestep**

**- Multi-body perturbations produced non-closed orbits and secular evolution**

**- Distinguished numerical error from genuine dynamical effects**



**The repository contains the final report and associated simulation code.**
