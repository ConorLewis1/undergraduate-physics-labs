# Fluid Instabilities

Experimental and computational investigation of the onset of instability in an electromagnetically driven shallow fluid layer.

Video-based particle tracking was used to reconstruct the flow field and determine the Reynolds number at which the initially banded flow became unstable.

## Methods
- Python data analysis
- Particle tracking and velocity reconstruction
- Reynolds-number and vorticity calculations
- Orthogonal-distance regression
- Segmented breakpoint fitting
- Monte Carlo uncertainty estimation

## Key Results
- Increasing-forcing transition: **Re_c = 68.4 (+0.6 / -0.9)**
- Decreasing-forcing transition: **Re_c = 59.2 (+0.9 / -0.7)**
- Separation: **Delta Re_c = 9.2**

The difference between the two transition points was consistent with path-dependent behaviour, although finite response times may also contribute.

The repository contains the final report and associated analysis code.
