# Astronomical Image Analysis

Astronomical imaging and time-series analysis of the spiral galaxy M91 and eclipsing binary NN Serpentis using ground-based IAC80 observations and TESS photometry.

## Methods
- Python data analysis
- CCD image reduction and stacking
- Source detection using DAOStarFinder
- Aperture photometry and photometric calibration
- Lomb-Scargle period analysis
- Phase-folded light curves

## Key Results
- Constructed multi-filter B, V and H-alpha imaging of M91 to examine galactic structure and star-forming regions
- Measured the light curve of NN Serpentis using aperture photometry
- Identified an orbital period of **0.13007 days** from TESS data
- Recovered the characteristic eclipse structure in the phase-folded light curve

The repository contains the final report and associated analysis code.
